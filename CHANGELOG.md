# Changelog

## 0.1.0-beta (not published yet)

First public version.

- **Settings:** 68 in three areas (performance, privacy, Explorer and taskbar), each with its
  source and evidence level. Every one can be undone, and Undo leaves alone anything changed by
  someone else since.
- **Restore points:** offered before applying (ticked by default); a page to see them, create one
  and open System Restore.
- **Other pages:** startup apps (the same switch Task Manager uses), cleanup, maintenance
  (SFC/DISM, disk health, driver backup), 30 built-in apps to remove or reinstall, drivers from
  Windows Update, and a history of everything PitCrew changed.
- **Presets and profiles:** "Essentials", "Gaming" and "More privacy" only tick boxes; profiles
  can be exported and imported.
- **Languages:** English, Portuguese (Brazil), Spanish, French, German, Russian, Turkish and
  Simplified Chinese.
- **Memory page:** RAM in use and the programs using the most, a polite way to close them, and
  Windows' own memory test. No "RAM cleaner" (it makes things slower).
- **More maintenance:** optimize drives (TRIM/defragmentation), read-only disk check, DNS cache.
- **Easier lists:** filter by state (applied, not applied, installed, on/off, ticked), tick all
  shown, untick all, and a count of what is ticked.
- **Light and dark themes** following Windows, PitCrew's own dialogs instead of Windows message
  boxes, and the window no longer turns white while a job runs.
- **Language and theme remembered** when picked in the window.
- **Download:** `PitCrew.exe` launcher (asks for administrator, opens read-only if refused) and a
  release zip built from git; new icon; About page with the project's goal and its author.
- **Donations by Pix** on the About page and in the README: QR code, key and "copia e cola",
  generated by the project itself (no QR library downloaded).
- **Safety:** two independent security reviews before release; their fixes are covered by tests.
